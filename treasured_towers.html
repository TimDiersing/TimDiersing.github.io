Treasured Towers

A solo developed tower defense game for mobile. With turret cards that can be individually leveled, each with their own unique upgrade tree. And, separate player progression with permanent upgrades and higher rewards the farther you make it through the game.

  • Platform: iOS
  • Engine / Tools: Unity, Aseprite, Audacity

Tech highlights:

  • Object pooling for performance
  • Event-driven gameplay systems
  • Save-data architecture / JSON serialization
  • Mobile UI and responsive layouts
  • App Store deployment pipeline
