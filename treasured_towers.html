Treasured Towers

A solo developed mobile tower defense and collecting game. With individual turret card leveling that increase stats, unique upgrade trees per turret, and seperate player progression with permanent upgrades.

platform: iOS Unity / C#

Tech highlights:

  • Object pooling for performance
  • Event-driven gameplay systems
  • Save-data architecture / JSON serialization
  • Mobile UI and responsive layouts
  • App Store deployment pipeline
